# OCR：仓库根目录上传 PDF 的文字版归档

本目录把**放在仓库根目录**的 PDF 全部转成可检索的 Markdown 文字版，一份原件对应一份
同名 `.md`。原件不移动、不修改；根目录再放入新的 PDF 后重跑脚本即可。

## 目录

| 文件 | 说明 |
|---|---|

| `scripts/pdf2text_ocr.py` | 生成脚本；直接复用 `09-文献清单/全文文本/scripts/pdf2text.py` 的转换规则 |

35 份全部转换成功，合计 1,025 页、约 132.1 万字。

## 处理规则

1. **优先用内嵌文字层**（`get_text(sort=True)`），保留页眉页脚与阅读顺序。
2. **只有三种页送 OCR**（RapidOCR）：整页扫描件；正文是扫描图、文字层只剩页眉页码；
   文字层字体编码损坏（私用区字符成片）。且只有 OCR 结果明显更长时才采用。
   第一批 398 页中只有 1 页需要 OCR（赖玉婷硕士论文第 1 页，CNKI 封面字体编码损坏）；
   第二批 627 页中 14 页需要 OCR：谭兆强文全篇 5 页（扫描件）、刘书星文 7 页、李曼琪与
   戴月洋碩論封面各 1 页。
3. **空白页不送 OCR**：渲染后墨迹比例 < 0.001 且文字层几乎为空，判为原件空白页，只留
   页标记。第一批 1 页（赖玉婷第 50 页）；第二批 3 页（余阳慧、张思迪、戴月洋各 1 页）。
4. **规范化只做机械处理**：删控制字符、私用区字符（换「•」）、压缩空行；不含汉字的
   英文数字行若是全角字形则折成半角。**中文正文与中文标点一律不动**，不做改写、
   翻译、纠错或补字。

每份 Markdown 头部写明原件名、SHA-256、页数、字数、文字来源、OCR 页、空白页与备注；
正文用 `--- 第 N 页 ---` / `--- 第 N 页（OCR） ---` / `--- 第 N 页（空白页） ---` 分隔。
页标记按 PDF **物理页序**，与书内印刷页码不同；印刷页码保留在正文中。

## 需要知道的几件事

- **`ntu-108-1.pdf` 不需要解密**：它是 AES 加密的 PDF，但加密只限制了复制与打印权限
  （无打开密码），文字层可以正常抽取；`pymupdf` 直接读出 235 页全文。原件保持原样，
  未做解密另存。
- **`blank.pdf` 名不副实**：文件名是浏览器 `about:blank` 的默认名，内容其实是 Gemini
  对话导出稿《台陆行政法选题评估与路径优化》，36 页，可检索。
- **`PDF_612498404.pdf` 是个人材料**：考研报名信息表，含身份证号、手机号、家庭与学籍
  信息。这是私有仓库；如需公开或外发，请先删除该文件与本目录对应文字版。
- **`ntu-108-1.pdf` 有 8 页只有 DOI 与页码**（第 24、25、76、77、163、214、215、225 页）：
  原件该页本身只有一个 DOI 页眉和页码（章节间的空白页），不是抽取失败。

## 与 `09-文献清单/全文文本/` 的关系

根目录这 35 份里，29 份中文文献与 `09-文献清单/中文文献PDF/` **字节相同**，本目录的
文字版与 `09-文献清单/全文文本/中文文献/` 的正文**逐字一致**（脚本每次运行都会复核）。
两处内容重复是有意为之：`全文文本/` 按文献来源分类，`OCR/` 按"根目录上传件"整体归档。
引用核对以原件为准。例外：`9xD7rCBP.pdf` 与 `赵德关｜….pdf` 在 `中文文献PDF/` 的入库
副本按著录规范另行命名（郭芳秀、赵德关），不参加字节比对，关系见各自头部备注。

## 重新生成

```bash
python3 OCR/scripts/pdf2text_ocr.py
```

依赖：`pymupdf`（必需）；扫描页 OCR 另需 `rapidocr-onnxruntime`。
脚本只读根目录 `*.pdf`，覆盖本目录 `*.md` 与 `_manifest.csv`；任一文件转换失败或校验
不一致时脚本以非零状态退出。
