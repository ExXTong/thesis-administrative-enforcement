## 总链条（七步）

### 第 1 步｜规范定位：把问题钉在**一个要件**上

| | 内容 |
|---|---|
| **P1** | 法释〔2018〕1号 **§155(一)第4项**「被申请人是该行政行为所确定的义务人」是**立案要件**；§155 末段：「对不符合条件的申请，应当裁定**不予受理**」 |
| **P2** | 处理义务人死亡的**全部**承接规则都在**立案之后**：《行政强制法》**§40(一)**（执行实施阶段的终结条款）、法释〔2016〕21号**§10**（执行程序中的变更）、**《民诉法解释》§473**（执行中） |
| **P3** | 《行政诉讼法》**§101** 的准用清单明文列有「中止诉讼、**终结诉讼**」，**不含「变更、追加当事人」** |
| **⇒ C1** | **要件与承接规则分处程序两端；且准用清单有缺口。**这是全案问题的规范内核 |

> **这一步是全文的地基**：抽掉 §155(四) 的"立案要件"属性，或抽掉 §101 清单缺口，整个命题坍塌。

### 第 2 步｜实证验证：**一个强预测变量**

| | 内容 |
|---|---|
| **P4** | 21 件样本中，「机关在申请时**是否已列承受主体**」预测 **19 件**：已列 3 件（渝0109、闽0124、粤0204）**全部准予**；未列者 20 件中 19 件走**退出型**出口 |
| **⇒ C2** | 法院实际**不处理**"谁是被执行人"，只处理"**接不接受这个申请**" |
| **P5** | 出口分布：不予受理 **1**／驳回执行申请 **4**／不准予执行 **3**／终结审查或终结执行 **7**／准许撤回 **4**（＝19） |
| **P6** | 其中只有**不予受理**（§155 末段）与**不准予执行**（§161 末段）有**明文复议**；驳回执行申请、终结审查、终结执行**均无** |
| **⇒ C3** | **救济配置不对称**——这是"出口选择"有真实法律后果的根据 |

### 第 3 步｜分歧定位：**控制变量反例**

| | 内容 |
|---|---|
| **P7** | **(2020)豫0802行审9号** vs **(2020)湘1302行审68号**：义务类型（罚款）／义务人数（**三人并处**）／死亡时点（申请前）／机关列名状态（**均未列**）**四栏完全相同，结果相反**（准予罚款部分 vs 对全部三人驳回） |
| **⇒ C4** | 分歧是**真的**，且**不能**由事实差异解释——"分歧只是个案事实不同"这一强反驳**不成立** |
| **P8** | 豫0802 把问题**推给执行阶段**并**分割**（「需查明张合玉的遗产……以决定是否终结**对张合玉的**执行」）；湘1302 把问题**退回机关**并**拒绝分割**（「主体不适格……可重新提交」——连两名健在义务人一并驳回） |
| **⇒ C5** | **分歧的落点是「审查范围与诉的可分性」，不是"谁是被执行人"** |

> 这一步是**全文最有价值的新发现**，也是旧命题必须改写的原因。

### 第 4 步｜涵摄分析：**两个方向都堵住**

| | 内容 |
|---|---|
| **P9** | 以**死者**为被申请人 → 死者**无权利能力**；以**继承人**为被申请人 → 继承人**不是"该行政行为所确定的义务人"** |
| **⇒ C6** | §155(四) 在义务人死亡时**两个方向都无法满足** |
| **P10** | §40(一)「**义务承受人**」是**否定性要件**（其规范指向是"**没有**承受人时"的出口；"有承受人"时**不**终结，但法条**不说明**后续怎么办）、**全法无定义**、"承受"全法**仅 2 次且均在 §40**、**且它是立案后规则** |
| **⇒ C7** | 无法用它**正面**判断"谁是适格被申请人" |
| **P11** | **§54 催告**的相对人只有「**当事人**」，继承人／遗产管理人**均未出现** |
| **⇒ C8** | 机关即便想接续，**催告也没有对象**（此项须限定为"**在被申请人仍为死者时**"；桂0202 是**孤例**） |

### 第 5 步｜对"终结"类出口的批评

| | 内容 |
|---|---|
| **P12** | 陕0622 经 **§101 → 《民事诉讼法》§151(二)**「被申请执行人死亡的，**终结诉讼**」→ 裁定「本案**终结审查**」 |
| **P13** | 但 §151(二) 是**三项复合要件**：「被告死亡**＋没有遗产＋也没有应当承担义务的人**」——陕0622 **一项未认定** |
| **P14** | 「**终结审查**」在行政非诉执行中**无出典**（出典分别在再审审查〔民诉解释§400〕与执行监督〔法发〔2023〕4号§12〕）；且非诉执行审查中**无"被告"格位** |
| **⇒ C9** | 该出口**要件不成就、依据不成立**——这是全文最硬的一处规范批评（黑帽三次攻击未倒） |

### 第 6 步｜比较法：**不是移植，是同构对照**

| | 内容 |
|---|---|
| **P15** | **德国**：VwVG **§5(1) 明文列举**准用 AO「§§262–267」→ **AO §265** → BGB／ZPO（**ZPO §778**：承认继承前**仅得对遗产**执行；**ZPO §779**：已开始的执行在遗产中**续行**，继承人未承认或不明时法院选任**临时特别代理人**） |
| **P16** | **日本**：国税徴収法 **§139(1)** 死亡不中断执行＋**§139(2)** 拟制（**但书**：机关明知死亡时不适用）；**§51** 先扣继承财产＋**换押**。**对继承人用"督促状"（通則法§37），"納付催告書"只对第二次纳税义务人／保证人** |
| **P17** | **台湾地区**：《行政執行法》**§24Ⅴ 直接列举**「繼承人、遺產管理人或遺囑執行人」；§26 準用強執；**強執§5Ⅲ/Ⅳ**（执行开始后死亡得续行；继承关系不明时**选任特别代理人**）；**法務部 99 年函专门处理"送達後、移送執行前"死亡** |
| **⇒ C10** | 共同点：①死亡**不停止程序**；②承接主体**都有明文**；③**分层独立于程序** |
| **P18** | **VwVG §5(1) 与 §101 同构而精度不同**——德国清单**列了**对继承人执行的条号（§265），我国清单**没列**"变更、追加当事人" |
| **⇒ C11** | **这解释了为何德国无争议而我国有争议**，并表明这是**可解释的问题**，不是只能等立法 |

### 第 7 步｜范围层：**分层判准**（本轮新增）

| | 内容 |
|---|---|
| **P19** | 《行政强制法》**§12(一)** 把「**加处罚款或者滞纳金**」列为**行政强制执行的方式**；**§45** 规定其前提（金钱给付义务＋逾期不履行）与**封顶**（不得超出原义务数额） |
| **P20** | **§35** 要求"作出强制执行决定**前**应当事先**催告当事人**"；**§37**「**经催告**，当事人逾期仍不履行，且无正当理由的，**可以作出强制执行决定**」 |
| **⇒ C12** | 加处罚款是**执行罚**，其成立以"**对当事人催告**"为前提 |
| **⇒ C13** | 死亡在 **§37 决定之前** → 催告不能完成 → **§37 要件不成就 → 不发生** |
| **⇒ C14** | 死亡在 **§37 决定之后** → 已成立但**不随继承移转**（执行罚具**人身专属性**；**德国 AO §45(1) 明文排除 Zwangsgelder**；陈思融 p139 对滞纳金持同一立场） |
| **⇒ C15** | **两条路径不同、结论一致：加处罚款不及于遗产** |
| **P21** | **罚款**是**制裁性行政行为**（《行政处罚法》§9），针对**既往**违法行为，**不具**人身专属性（陈思融 p140）→ **可及于遗产** |
| **⇒ C16** | **分层判准成立**：**处罚（可继受）／执行罚（不可继受）**——这正是大陆法此前缺失的那一块 |
| **P22** | 但《民法典》**§1161** 的宾语是「**税款和债务**」，**未提罚款**；"债务"是否含**公法罚款义务**，文义可疑 |
| **⇒ C17** | **罚款本金的规范依据仍是缺口**（否定侧有依据、**肯定侧没有**）——这一**不对称本身就是发现** |

## 结论（一句话）

> **不是"谁是被执行人应当如何确定"，而是「§155(四) 这一立案要件在义务人死亡时如何涵摄、法院在要件不成就时应当选哪个出口、以及各出口的救济配置是否对称」——而这三问的答案，中国大陆现行法只给了半个。**

### 本文主张（严格限定版）

> **接续（查明承受主体 → 列为被申请人 → 对其重新告知与催告）应在申请前由机关完成；法院在接续不到位时应当统一出口（立案前→不予受理；已立案→不准予执行）并明确救济。**
>
> **本文不主张"应当变更被执行主体"**——按裁定主文口径，21 件中"变更"这一出口为 **0 件**；21 件中**没有一件**对"公法金钱给付义务能否由继承人承受"作实体法论证。
