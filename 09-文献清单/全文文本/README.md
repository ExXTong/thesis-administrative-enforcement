本目录是 `09-文献清单/` 下文献原件的**文字版**：把 PDF 的文字层抽出来，扫描页补做 OCR，
网页文章抽正文，统一存成 Markdown，便于全文检索、摘抄、核对引文。

原件仍以 `中文文献PDF/`、`外文文献PDF/` 为准，本目录**只读不改原件**；任何一处与原件不一致，以原件为准。

## 每份文件的头部与分页

每份 Markdown 开头有一段元信息，说明原件路径、页数、字数、文字来源、哪些页做了 OCR、
哪些页原件即为空白，末尾注明生成脚本与日期。正文用页标记分隔：

- `--- 第 12 页 ---`：文字来自 PDF 内嵌文字层；
- `--- 第 12 页（OCR） ---`：该页原本没有可用文字层，文字由 OCR 得到，**准确率低于文字层**；
- `--- 第 12 页（空白页） ---`：原件该页没有内容（扫描白页、书页间空白页）。

页标记按 PDF 物理页序，与书内印刷页码不一定相同；印刷页码通常保留在正文里。

## 处理规则

1. **优先用内嵌文字层**（`get_text(sort=True)`），保留页眉页脚与阅读顺序，不做改写。
2. 只有下列页面送 OCR：整页扫描件；正文是扫描图、文字层只剩页眉页码；文字层字体编码
   损坏（私用区字符成片）。且只有 OCR 结果明显长于原有文字时才采用 OCR 结果。
3. 空白页（渲染后墨迹几乎为零）不送 OCR，只留页标记。
4. 网页文章（`.html`）取 `<article>` 正文，按段落、标题、列表转写，去掉导航与页脚。
   特判三种官方/判例页面：德国 `gesetze-im-internet.de` 条文页取 `div.jnhtml`（条号标题取 `div.jnentitel`）；
   判例汇编站（如 HallApproved）取 `div.opinion-text` 整块判决正文；日本 e-Gov 法令 `.xml` 机械抽取本則与附則各条（条号、条标题、各款），不翻译。
5. 规范化只做机械处理：删控制字符、私用区字符（换成「•」）、压缩空行；纯英文数字行若是
   全角字形则折成半角。**中文正文与中文标点一律不动**，不做任何改写、翻译、纠错或补字。

## 加密的 PDF

台大论文系统（TDR）导出的 PDF 常带「标准安全处理器、128-bit AES、用户口令为空、仅设所有者口令」的加密：
任何阅读器都能打开，但权限位禁止提取文字，`pdfinfo` 显示 `Encrypted: yes (print:yes copy:no ...)`。
这类文件不需要猜口令，用脚本重写一遍即可，**内容（文字与图像）逐页不变**：

```bash
python3 09-文献清单/全文文本/scripts/decrypt_pdf.py 原件.pdf 输出.pdf
```

脚本只去掉 `/Encrypt` 字典与权限限制，不重新排版、不重新栅格化（图片流按原字节保留）；
写完后重新打开输出，逐页核对文字与 48dpi 渲染像素的 SHA-256，任何一页不一致就删掉输出
并非零退出。真的需要口令才能打开的文件，脚本报错退出，不做任何猜测或暴力尝试。

`論行政法上義務之概括繼受_邱稚宸.pdf` 就是这样处理的：原始件是仓库根目录的 `ntu-108-1.pdf`
（台大 TDR，DOI `10.6342/NTU202000774`，235 页），解密副本放在 `中文文献PDF/`，根目录原件未动。

## 重新生成

```bash
python3 09-文献清单/全文文本/scripts/pdf2text.py
```

依赖：`pymupdf`（必需）；`rapidocr-onnxruntime`（扫描页 OCR）；`beautifulsoup4`（网页文章）。
脚本只读原件，输出覆盖本目录下的 `中文文献/`、`外文文献/`、`原始法条/` 与 `_manifest.csv`。
新增文献后重跑即可；新增原件若为扫描件，会按同一规则自动 OCR。
