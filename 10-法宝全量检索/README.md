## 一、这个包是什么

把北大法宝「**非诉行政行为申请执行审查**」案件类型下、**含 20 个死亡/继承类关键词**的全部案例，
用**时间切片**的方式尽可能检索出来，落盘为本地 JSON + 汇总 CSV。

**目的**：给论文《行政非诉执行审查中主体要件的涵摄与出口—救济配置》建立**实证样本基础**。

## 五、⚠️ 数据质量与已知限制（**务必阅读**）

| # | 限制 | 说明 |
|---|---|---|
| **1** | **去重键是「法宝链接」不是案号** | 法宝存在同一案号对应不同链接的记录（A4 实测 57 处）。用案号去重会误删。 |
| **2** | **法宝 Total 含重复计数** | 同一切片内可能返回重复行（A1 实测：`(2015)馆行审字第27号` 同切片出现 2 次）。故覆盖率按 total 计算会**高估**。 |
| **3** | **批量同源严重** | 同一法院同一日可批量立案（湖南资兴市法院 2020-01-08 单日 195 条；天津河北区法院 2018-04 系列；河北河间市、湖南湘潭岳塘区）。已加标记列，**分析时须整批剔除**。 |
| **4** | **`_分类` 是自动正则判定，有假阳性** | 已收紧三轮（排除"前妻病故""已故的父母"等），但**重要结论必须回原始正文核对**。 |
| **5** | **覆盖不完整** | 全部 20 个词合计约 12,451 个"案件-槽位"，本次受预算限制仅取到部分。各词覆盖率见 `_未拿全清单.md`。 |
| **6** | **法宝 `fulltext` 是宽匹配** | 且不覆盖数字短语。"0 件"只能写"在法宝可得范围内 0 件"。 |
| **7** | **`--court` 维度既不按层级、也不穷尽** | ① 传 `基层人民法院` 等**恒返回 0**（实为法院名字面匹配）；② 改用 `区/县/市人民法院`**仍有漏**（A6 实测 2018 年 283+404+120=807 vs 全量 877，**缺 70**）。**⇒ 该维度不可用于需要完整性的场合**，只能用【审结日期】等比切分。此坑全队损失约 150 次调用。 |
| **8** | **`documentAttr` 亦非穷尽** | A6 实测：2014 年 `裁定书` 仅 103/156。 |
| **9** | **覆盖率（关键词「死亡」2008–2017）** | 2008–2015 **八年 100% 拿全（348/348）**；2016 = 576/668；2017 = 266/800；叶内合计 1190/1816 = **65.5%**。2016 有 3 个**单日片** total=31/36/25，日期维度已切无可切。 |

## 六、检索参数（可复现）

```bash
# 客户端
python3 scripts/pku.py search --keyword "病故" \
    --start 2020.1.1 --end 2020.12.31 \
    --court 区人民法院 \
    --out cases/X/病故__2020__区.json
```

| 参数 | 值 |
|---|---|
| `caseClassName` | `非诉行政行为申请执行审查` |
| 关键词（20 个） | 死亡 · 继承 · 继承人 · 去世 · 已故 · 遗产 · 无遗产可供执行 · 死者 · 义务承受人 · 已死亡 · 死亡证明 · 身亡 · 病故 · 无义务承受人 · 被执行人死亡 · 当事人死亡 · 遗产管理人 · 无人继承 · 义务人死亡 · 催告继承人 |
| 年份 | 2008–2026 |
| 切片维度 | **年 → 月 → `区/县/市人民法院` → 旬**（不要用法院层级！） |

### ★ 关键方法：时间切片绕过"每次 20 条、不可翻页"

法宝硬限制：**每次最多返回 20 条，且无翻页参数**。绕过方法：

```
1. 查询 (关键词 × 年)
2. Total ≤ 20  → 已拿全
3. Total > 20  → 按「月」切
4. 月仍 > 20   → 加「区/县/市人民法院」三档
5. 仍 > 20     → 切「旬」
6. 仍 > 20     → 记入"未拿全清单"，停止
```
