6. 使用限制与阅读纪律（务必先读）

  1. 材料来源是"北大法宝 MCP 返回文本"，不是网页抓取：法宝网页端有反爬（web_fetch 返回 HTTP 200 但正文为空）。未核印刷版式；关键条文建议以纸质公报或官方文本终局核验（尤其法行〔2000〕16号、《行政强制法》§40、法释〔2018〕1号 §155）。
  2. 法宝 MCP 无期刊库 → 撞题文献须另找通道；无"被引用情况"接口 → 16号 的"20 件引用裁判"统计是下限口径（检索式 get_case_list(fulltext="通知申请机关变更被执行人", title="非诉")）。
  3. 若干文件带"⚠️ 性质与适用性限定"（如 (2026)川0302行审45号、(2026)甘0302行审19号 属"死亡后多领待遇的不当得利"，不计入本命题）——请先读该限定再引用。
  4. 本材料经历两轮自我更正，以下表述已作废，请勿继承： - ~~"行政侧没有通道／缺少接入遗产管理人的一步／行政执行不能变更被执行主体"~~ → 《行政诉讼法》§101 转致通道现成且实务已在用（渝0109行审83）； - ~~"两部现行有效司法解释规则相反／内部冲突"~~ → 是分工（§10 主体路径／§473 标的路径）； - ~~"大陆存在制度空白"~~ → 至少有《行政强制法》§40(一)、《民法典》§1145–§1149、法释〔2016〕21号 §10 三套装置。
  5. 上游 juris 产出中的部分统计已被推翻（如"行政裁判 0 件"、"T8 未检到"）。凡与材料包 01／03／03b／03c 冲突的，以材料包为准（材料包为逐字一手核验）。
  6. 材料包内行政非诉执行的"金钱给付义务＋放弃继承"正面案例为 0 件，这是已知空白，不是遗漏。
