## 6. 阅读纪律（**5 条，违反其一结论即不可用**）

1. **材料来源**：全部法律文本取自**北大法宝 MCP 返回**，**不是网页抓取**（法宝网页端有反爬，`web_fetch` 返回 HTTP 200 但正文为空）。**未核印刷版式**——关键条文（法行〔2000〕16号、《行政强制法》§40、法释〔2018〕1号 §155）请自行终局核验。
2. **法宝 MCP 的能力边界**：**无期刊库**（撞题文献须另找通道）；**无"被引用情况"接口**——16号 的"20 件引用裁判"是**下限口径**，不是全量。
3. **注意"⚠️ 性质与适用性限定"**：`(2026)川0302行审45号`、`(2026)甘0302行审19号` 属"**死亡后多领待遇的不当得利**"，**不计入本命题**。**凡文件顶部有此限定，先读限定再引用。**
4. **已作废表述黑名单（不要继承，发现残留请指出）**：
   - ~~"行政侧没有通道／缺少接入遗产管理人的一步／行政执行不能变更被执行主体"~~ → **§101 转致通道现成且实务已在用**（渝0109行审83）；
   - ~~"两部现行有效司法解释规则相反／内部冲突"~~ → **是分工**（§10 主体路径／§473 标的路径）；
   - ~~"大陆存在制度空白"~~ → 至少有《行政强制法》§40(一)、《民法典》§1145–§1149、法释〔2016〕21号 §10 **三套装置**。
5. **历史件与已被推翻的统计**：上游 juris 产出中的 `…-矩阵表-阶段×义务类型`、`…-材料汇编-死亡全流程`、`…-待核与未检到清单` 及 `北大法宝查询清单/Prompt` 均为**历史件**；其中"**行政裁判未检到／0 件**""**T8 未检到**"等统计**已被 R8／R9／材料包 `03c` 推翻**。**凡与材料包 `01`／`03`／`03b`／`03c` 冲突的，以材料包为准**（材料包为逐字一手核验）。
   - 历史件**可以读**（了解选题由来与当时判断），但**不得作为论据引用**。
