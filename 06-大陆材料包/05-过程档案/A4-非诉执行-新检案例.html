一、★ 必须先更正的一件事：(2025)湘04执复10号 与"死亡"无关

用户提供的第二份 PDF（文件名作"山东俊某商贸有限公司、李某静等行政非诉执行执行复议裁定书"）就是 (2025)湘04执复10号。全文"死亡"出现 0 次。

案情：被执行人＝山东俊某商贸有限公司（法人）；衡山县市监局请求追加三名股东为被执行人（认缴出资加速到期、财产混同）；法院驳回，理由是"《变更追加规定》……并不适用于执行行政决定的非诉执行"，并援引法行〔2000〕16号论证"即使要变更行政处罚对象，也应由行政机关进行变更"。

→ 该案不属于任何"死亡时点"，必须从"五条死亡路径"里删除（这是我第三次同类更正：前两次是 (2024)青0122行审17号＝法人注销、P0-2 漏"实施阶段"限定）。 → 但它对论文仍然关键：它是"反对参照适用"的最强版，且其论据是 16号——用 16号 反推"变更只能由机关作出"。这在论文第三章 3.1 正是要正面回应的对象。

二、★★ 最有价值的新发现："发动主体"有现成裁判答案（直接补进第三章 3.4）

模式一：法院要求申请人提交"遗产或义务承受人"证据，不提交则不准予执行——青州系列 3 件

(2020)鲁0781行审365号、366号、378号（山东青州市人民法院，2020-07-20，同一法官）：

「本院经调查，被执行人王法祖于2018年5月8日因死亡被公安机关注销户口，查明上述情况后，本院要求申请执行人提交被执行人的遗产或者义务承受人的有关证据，以确定是否变更被执行人，申请执行人至今未提交相关证据证实。」 「本院认为，……被执行人死亡，申请执行人应提交被执行人的遗产或者义务承受人，以确定承担义务主体。被处罚人死亡后，申请执行人要求死者承担责任的法律依据明显不足。」（依《行政强制法》§58、法释〔2018〕1号 §161 → 不准予强制执行）

→ 这是"由谁发动变更"的现成答案：法院不依职权变更，而是要求申请执行人自己举证并提出变更；不提出 → 不准予执行。与我在写作方案 3.4 提出的立场（由申请执行的行政机关以变更申请方式发动）完全一致，且有裁判支撑。

模式二：上级法院确认"法院应通知申请机关变更"（16号 的程序含义）——**

(2020)粤06行审复10号（佛山中院，2020-12-10，非诉执行审查复议）：

「参照上述答复的规定，原审法院应当通知佛山市生态环境局，由其决定是否变更被执行人，并对变更后的被执行人是否适格以及案涉处罚决定是否符合执行条件依法进行审查。原审法院在未通知申请人是否变更被执行人的情况下，直接以被执行人主体不存在为由裁定驳回执行申请不当，本院予以纠正。」 裁定：撤销一审裁定，发回重新审查。

→ 明确 16号 的程序含义：通知义务在法院，决定权在机关。

模式三：法院发《工作联系函》限期变更，逾期即驳回

(2025)渝0108行审21号（重庆南岸区法院，2025-04-11）：被执行人（加工厂）已注销，法院「向申请执行人送达《工作联系函》，要求……五个工作日内变更被执行人。申请执行人……逾期未向本院提出变更被执行人申请」→ 驳回强制执行申请。

→ 与青州模式同构，且是2025 年最新例。

三、新增的"死亡"案件（行政非诉执行）

3.1 第六条路径：撤回（此前五条路径中没有）

案号 法院／日期 机关撤回的理由（逐字）
(2024)黑1222行审20号 黑龙江兰西县法院 2024-08-03 「申请执行人……于2024年8月2日以被执行人死亡为由向本院申请撤回强制执行申请」→ 准许撤回
(2019)粤7101行审2668号 广州铁路运输第一法院 2019-04-15 社会抚养费征收决定；「2019年3月29日，申请执行人以被执行人死亡为由，向本院提出撤回强制执行申请」→ 准予撤回
(2017)辽0727行审168号 辽宁义县法院 2017-08-11 「申请执行人以被执行人死亡、未确定继承人为由申请撤回强制执行申请」→ 准许撤回

→ 意义：义务人死亡后，机关最常做的既不是驳回也不是变更，而是自己撤回（3 件）。这使"路径"从五条变六条，也说明机关自己也找不到出口。

3.2 "义务承受人"在实务中的常规用法：天津河北区法院系列（20+ 件）

(2018)津0105行审71／72／77／85／87／89／93／98／105／108／110／111／124／136／150／156／157／188／193……号（天津市河北区人民法院，2018 年，房屋征收补偿决定非诉执行）：

  • 案名直接写作「佟守信（已故）的权利义务承受人」等；
  • 事实：被征收人已故 → 征收部门与"权利义务承受人"协商、向其公告送达决定书与催告书；
  • 结果：准予强制执行（《行政诉讼法》§97、《行政强制法》§53、《办理征收补偿决定案件若干问题的规定》§1、§9）。

→ 意义（直接修正写作方案 2.1）：「义务承受人」虽未经法律定义，但在征收领域已是行政机关与法院的通用表述（20+ 件系列案）。因此 2.1 不能写"这一概念无人使用"，而应写"概念被广泛使用、却无定义、也无可供自然人适用的变更程序"——这比原表述更准、也更难被反驳。
