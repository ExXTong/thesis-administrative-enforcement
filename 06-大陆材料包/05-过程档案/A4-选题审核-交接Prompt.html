# 领域与选题
- 领域：行政法 / 行政诉讼法（兼及民事执行的比较），中国法视角。
- 选题：**义务人死亡后，公法上金钱给付义务（罚款、税款、滞纳金、加处罚款等）的执行——被执行主体如何确定**。
- 论文性质：**解释论 + 比较法**，**不写立法建议**。

# 当前命题（请审核它）
1. **概念空隙**：《行政强制法》§40(一) 以「**义务承受人**」为终结执行的要件之一，但**全法未定义该概念**；法释〔2018〕1号 §155(四) 又要求被申请人必须是「**该行政行为所确定的义务人**」。→ 实体法有范畴、程序法无入口。
2. **真正的问题是"参照适用的边界"**：行政非诉执行**有**通道——《行政诉讼法》**§101 是转致条款**（"……简易程序、执行等……本法没有规定的，适用《中华人民共和国民事诉讼法》的相关规定"），实务也**已在用**；但把它用进来时，**三处边界没有定论**：
   - **范围**：法释〔2016〕21号序言自限于"为正确处理**民事执行**中变更、追加当事人问题"→ 能否转致进非诉执行？
   - **阶段**：法释〔2018〕1号 §155(四) 在**立案审查**关口关闭通道；§101 的转致在**执行实施**阶段展开。
   - **发动主体**：民事是"**申请执行人申请**变更/追加"；法行〔2000〕16号 是"**人民法院通知申请机关变更**"；而《行政强制法》全法「**申请执行人**」**0 次**。
3. 由此，行政实践**分裂为五条路径**（见下），**并非"无法可依"，而是"依据不统一"**。

## C. 民事侧（作为参照系，而非"有装置的一侧"）
- **收敛路径**：「确定遗产管理人 → 追加其为被执行人 → 在遗产范围内执行」，且**遗产管理人并非责任承担主体、不得执行其自有财产**：
