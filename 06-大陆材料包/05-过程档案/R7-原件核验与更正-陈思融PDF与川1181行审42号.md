## 一、裁定书 `(2017)川1181行审42号`（**推翻本 run 的"行政裁判 0 件"结论**）

- 法院／日期：四川省峨眉山市人民法院，2017-11-03；**非诉行政行为申请执行审查**。
- 处罚决定：乐市国土资中分罚［2015］第61号（责令退还土地＋限期拆除＋罚款 9706.50 元）。
- 逐字关键事实：「另查明：**被执行人冯加强已于 2017 年 10 月死亡**，其继承人冯加元**表示愿意继承冯加强所有债权债务**，履行市中区国土分局作出的行政处罚决定，**本院依法变更冯加元为本案被执行人**。」

## 二、两份司法解释的官方核验（**关闭 W2/W4，即上游 P0-1、P0-2**）

均取自**最高法官网存档页**（本 run `raw/` 已存）：

| 规范 | 逐字要点 | 存档 |
|---|---|---|
| **法释〔2016〕21号 §10（2020 修正现行文本）** | 「作为被执行人的自然人死亡或被宣告死亡，申请执行人申请变更、追加该自然人的**遗产管理人、继承人、受遗赠人**……为被执行人，**在遗产范围内承担责任的**，人民法院应予支持。」→ **2020 修正合并文本中已无"可以直接执行遗产"那句** | `raw/fs2020-21-xiugai18jian-court-282661.html` |
| **《民诉法解释》§473（2022 修正）** | 「作为被执行人的公民死亡，其遗产继承人没有放弃继承的，人民法院可以裁定变更被执行人，由该继承人在遗产的范围内偿还债务。**继承人放弃继承的，人民法院可以直接执行被执行人的遗产。**」 | `raw/msfjs-2022xiuzheng-court-353651.html` |
| 《民诉法解释》§470（2022 修正） | **法人或其他组织终止条**：分立、合并→变更后的法人/组织；被注销且有承受人→变更承受人 | 同上 |
| 《民诉法解释》§475（2015 原文） | ＝2022 修正 §473 的前身，**同样含"可以直接执行被执行人的遗产"** | `raw/msfjs-2015yuanwen-court-13241.html` |

**结论**：★"2020 删除直接执行遗产"由**非官方转录升级为最高法官网一手文本**；★《民诉法解释》§473 **保留该句**——**两部现行有效司法解释规则相反，内部冲突成立**。且二者装置形态不同：前者为"**当事人申请**变更/追加"，后者为"**法院可以裁定**变更 + 放弃继承时直接执行遗产"。
