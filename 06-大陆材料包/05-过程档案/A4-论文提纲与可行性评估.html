A4 论文提纲与可行性评估（2026-09-26）

依据：本轮全部记录（选题由来 → 材料收集 → 用户两轮批评 → 时点聚焦 → 比较法回归 → 五章初稿 34,444 字） 用途：判断能不能写、按什么提纲写、写不了往哪转向

一、能不能写：判断与前提

结论：能写。但论点必须改写一次。

1. 现在的论点（初稿所用）

行政非诉执行对"义务人死亡"没有自己的装置；本文主张经《行政诉讼法》第101条转致民事变更规则，由机关申请、法院审查，变更继承人或遗产管理人为被执行人，责任限于遗产。

问题：这个论点的落点是"补一个程序缺口"。它的强度完全取决于一个判断——§101 转致能否成立。而这个判断有明确的反对方（(2025)湘04执复10号），且用户自己也对渝0109的"借民事规则"做法有疑虑。一旦§101被否，全文的解决方案就塌了，论文只剩"四个法院四种做法"的描述。

2. 应当改成的论点

《行政强制法》第40条第1项的"义务承受人"与法释〔2018〕1号第155条第4项的"该行政行为所确定的义务人"不是同一概念：前者是一个实体归属范畴（谁承受义务），后者是一个程序适格范畴（谁能当被申请人）。行政非诉执行在两个概念的接缝处没有装置——实体上承认有"承受人"，程序上却要求必须是"原义务人"。三个法域的共同选择是把这两件事分开处理：程序上不因死亡而停止，实体上按义务性质限定范围。本文据此提出"入口—发动—范围"三段式解释论方案。

这个论点的好处： - 它是一个概念错位的发现，不依赖§101是否成立——即使§101被否，错位本身仍然成立，只是解决方案需要换（转为实体法路径或立法论）； - 它有比较法上的结构支撑（三法域都把"程序续行"与"责任范围"分开）； - 它把渝0109的五处瑕疵从"法院做错了"提升为"两个概念被混用"——理论层次更高。

3. 一个必须接受的限制

这篇论文的天花板是"厘清关系"，不是"解决难题"。 它能做到的是：说清这个时点上发生了什么、为什么四个法院做法不同、比较法上别人怎么处理、现行法下可以怎么接。它做不到的是：论证出一个唯一正确的答案。原因很简单——这个问题在现行法上本来就没有唯一答案，凡是声称有的，都会像渝0109那样留下论证缺口。

二、全文提纲

体量：正文约 3.0–3.4 万字。章序建议：问题 → 比较法 → 实务 → 方案 → 结论（即初稿顺序）。 另一可选章序：问题 → 规范真空 → 实务 → 比较法 → 方案 → 结论（把比较法放后面，让它直接服务于方案）。两者都可，但不要混用。

节 核心论断（可被反驳的一句话） 支撑材料

第五章　结论（2,500–3,500字）

  1. 问题性质：不是规则冲突，是两个概念没有对接装置
  2. 比较法启示：三共同点＋一个限定
  3. 方案三段
  4. 与既有研究的关系（分工而非对立；两点不同意见；一点承认）
  5. 未尽事项（五项）：只处理金钱给付义务／只处理一个时点／"停止计算"的反面未论证／行政自执未纳入／比较法深度有限

三、三个真实风险与应对

风险一：§101 转致被否（最致命）

风险内容：若评审接受湘案立场（民事变更规则根本不适用于非诉执行），则第四章方案整体失效。

应对： 1. 把§101论证从"结论"降为"选项"：4.1 不写成"§101当然适用"，而写成"§101是唯一可能通道，其成立需回应三个反对理由"；然后逐一回应，最后说"若此路不通，则只能走实体法路径（另作继受决定）或等待立法"。 2. 增设一节"退一步的方案"：若§101不成立，则在窗口期内只有两条路——①机关撤回（现状）②机关依《民法典》§1161另作催告与主张。承认方案的可废止性，比强推一个方案更稳。 3. 这也是把论点改为"概念错位"的好处：错位发现不依赖§101。

风险二：比较法的"共同点"落点偏薄

风险内容：三法域都有明文、我国没有——这个对比的结论容易滑向"我国应当立法"，而本文又声明不写立法建议。

应对： 1. 把落点从"有没有明文"改为"两件事是否分开"：三法域都把"程序续行"与"责任范围"分开处理，而我国把两者压在同一个条文群里（§40(一)＋§155(四)），这是结构差异而非"有无差异"。 2. 强化 2.5 的启示二：VwVG§5(1) 与 §101 同构而精度不同——这一条把"有没有明文"转化为"概括准用下的解释负担"，落点从立法转向解释，与全文立场一致。

风险三："停止计算"缺比较法支撑

风险内容：已在第二章2.6声明。若评审追问"凭什么停止计算"，仅靠《行政强制法》§45(2)的规范目的可能不够。

应对： 1. 补一个正面论证：加处罚款与滞纳金的功能是"施压"（促使义务人自行履行），而施压需要对象；义务人死亡后施压对象不存在，继续计算失去功能基础——这一论证与德国排除 Zwangsgelder 的立法理由同源，虽无明文，但逻辑上是德国明文除外规则的延伸。 2. 补一个反面回应（第四章待办第4项）：能否被义务人生前故意拖延规避？回答：①死亡是事实而非选择，与"恶意注销"不同；②若继承人有隐匿遗产等行为，可另行依§1161与执行异议处理；③停止计算只及于附随负担，本金仍及于遗产，逃避动机有限。

四、如果写不了：四个转向方向

判断标准：若§101转致论证不成立，且"概念错位"的落点被认为只是概念梳理，则应转向。

四、继续性负担的死亡界限（用户最初想写的） 《继续性公法金钱负担的死亡界限——加处罚款、滞纳金与执行罚》 加处罚款、滞纳金在义务人死亡后应否继续计算？执行罚（怠金）应否及于遗产？ 桂03行终209号（滞纳金＝征税行为）、苏1012行审8号（本金＋加处罚款一并执行）、德国AO§45(1)明文除外、日本§896但书、台湾釋621／622＋廖義男（四点结论）、§72、§32、§45(2) 是用户最初的兴趣所在；有明确的对立学说（廖義男）与实务分歧 我国规范材料薄（§32无终止事由、§72历次修订未涉死亡），主要靠比较法＋学理，实证支撑弱

转向建议

  • 若保留程序框架但§101风险高 → 走方向二（执行名义主观范围），把§101作为其中一个论据而非全部；
  • 若想写理论性更强的 → 走方向一（义务承受人概念），这是唯一完全不依赖转致的方向；
  • 若想追最新制度 → 走方向三（遗产管理人），材料最新且有官方案例；
  • 若回到最初兴趣 → 走方向四（继续性负担），但须接受实证薄、以比较法为主的代价。

五、动笔优先级建议

若按现在这个提纲继续（推荐）：

  1. 先补三项核验（都是一手材料，1–2小时可完成）： - 《行政诉讼法》§101 逐字文本； - AO §265 所准用的 BGB §§1958、1960(3)、1961 与 ZPO §§747、748、778、779、781–784 的内容； - 廖義男所引刑诉 §470 III 的现行文字与增订年份。
  2. 再改第一章1.2（把"五个失效点"改写为"两个概念的错位"）——这是全文论点的支点，改完之后第四、五章要跟着调；
