## 给智能体的工作约定

### 可以做的

- **文字校对**：错别字、标点、术语一致性（如「非诉执行」与「非诉行政执行」的统一）
- **格式规范化**：Markdown 表格对齐、标题层级、参考文献格式（GB/T 7714）
- **文献清单维护**：条目增删、字段补全、去重、按主题分类
- **交叉引用检查**：正文引用与 `09-文献清单/` 是否对得上
- **断链检查**：Markdown 内部链接、图片路径是否有效
- **机械性重构**：文件名统一、章节编号调整、把散落文件归入正确目录

### 不要做的

- **不要改写论证内容**。论文的核心论证（见 `01-选题与方案/A4-现在的论证逻辑.md`）是作者本人的学术判断，任何实质性表述变更都必须先提出、等确认。
- **不要删除或覆盖原始材料**。`08-原始件/` 与 `06-大陆材料包/` 是证据来源，只读。
- **不要"修正"引用的法条与判例**。你若认为某处引用有误，请指出并附依据，由作者核对，不要直接改数字或案号。
- **不要碰 `05-比较法与台湾/` 里的讲义摘录**。该部分涉及第三方版权，只能作为内部参考，不得大段复制到论文正文。

### 交付要求

- 一次只做一件事，改完在 PR 说明里逐条列出改了什么、为什么。
- 涉及学术判断的地方，宁可停下来提问，不要自作主张。
- 中文正文用全角标点；引号统一用「」还是""以现有文本为准，不要混用。
