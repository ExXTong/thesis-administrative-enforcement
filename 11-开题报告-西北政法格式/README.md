## 七、引注体例与本次修订（2026-11-10）

### 1. 体例

依《法学引注手册》（北京大学出版社 2020 年版），采**页下脚注、整篇连续编号**：

- 图书：作者：《书名》，出版社年版，第×页。
- 期刊：作者：《篇名》，载《刊名》×年第×期，第×页。
- 文集：作者：《篇名》，载编者编：《书名》，出版社年版，第×页。
- 学位论文：作者：《题名》，学校年份学位论文，第×页。
- 台湾地区文献照录繁体题名与作者名；外文文献按手册的英文示例（作者、斜体篇名、刊名、卷、页、年）。
- 直接引用标具体页码；间接引用标「参见」及页码；重复引用写「同前注×，第×页」。
- 案例首次出现给「法院全称＋案号＋裁判日期＋法宝链接」，再次出现只给案号。

Markdown 无法生成真正的页下注，故各分册把脚注集中列在该栏末尾，编号以栏号冠首（`1-`／`2-`／`3-`），**互不重复**；`make.sh` 合并后编号保持唯一，转 Word 时按出现顺序转成页下脚注即可。`04-主要参考文献.md` 按教务处的「参考文献栏」要求不逐条编号，只在该栏第（八）节列出待核项。
